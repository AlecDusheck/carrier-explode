# Carrier icons

One icon per carrier, `<slug>.svg`, shown at 20px (14px in chips). Each is one of three kinds:

| Kind | In this folder |
| --- | --- |
| Redrawn | Our own SVG of the logo, in the style below. |
| Original | The unmodified logo file is in [`brand/`](brand/README.md); the icon here is the template tile. |
| Template tile | A neutral tile with the carrier's initials. |

## Style

- Every icon, redrawn or template, uses the same `viewBox="0 0 24 24"` and the same tile as `../ios/` and `../android/`: `x` and `y` of 0.5, 23 by 23, `rx` 5.5. They all render at one size.
- The tile is the brand colour, with a subtle top-to-bottom gradient if it helps. A logo that is dark on white sits on a white tile with a 1px `#9a958a` stroke.
- A simplified mark is centred on the tile, legible at 14 to 20px: few shapes, strokes of 1.5 units or more, no text or fonts.
- Redrawn by hand from a checked reference. Official path data is not copied.
